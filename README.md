## 🚀 Featured Projects

### 🛡️ AegisHMAC

> An API authentication gateway that uses HMAC-SHA256 to verify signed requests to REST and GraphQL endpoints.

- Uses timestamps and MongoDB-backed nonces to guard against replayed requests.
- Includes Python and TypeScript client SDKs and a React dashboard for key rotation and audit logs.

**Stack** · FastAPI, Python, TypeScript, React, MongoDB, GraphQL  
🔗 [Explore AegisHMAC](https://github.com/AchalRaj0709/aegis-hmac)

### 📬 Outreach Pipeline

> A Python CLI that starts with a company domain and runs a B2B outreach workflow.

- Finds similar companies, identifies decision-makers, and enriches their work contact details.
- Shows the recipient list for review before syncing contacts and sending personalized emails through Brevo.

**Stack** · Python, CompanyEnrich, Prospeo, Brevo  
🔗 [Explore Outreach Pipeline](https://github.com/AchalRaj0709/outreach-pipeline)

### 💰 ArthVeda

> A personal finance dashboard for tracking income, expenses, and savings.

- Shows spending by category, calculates a savings-based financial health score, and flags unusually large expenses.
- Exports a financial summary as a PDF or transaction history as a CSV.

**Stack** · React, Tailwind CSS, Node.js, Express, MongoDB, Recharts  
🔗 [Explore ArthVeda](https://github.com/AchalRaj0709/ArthVeda)
